## ⚙️ Local Setup & Quickstart

To run this portfolio locally on your machine:

### Option 1: Via Laragon (Recommended for Windows)
1. Clone or copy this repository into your Laragon `www` directory:
   ```bash
   cd C:\laragon\www
   git clone https://github.com/mirwan10522114-jpg/PORTOFOLIO.git
   ```
2. Start Laragon (Apache service).
3. Access in your browser:
   ```
   http://localhost/PORTOFOLIO/
   ```

### Option 2: Via VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Right click on `index.html` and select **"Open with Live Server"**.
3. Browse to `http://127.0.0.1:5500/index.html`.

### Option 3: Via Python Built-in Server
```bash
git clone https://github.com/mirwan10522114-jpg/PORTOFOLIO.git
cd PORTOFOLIO
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
